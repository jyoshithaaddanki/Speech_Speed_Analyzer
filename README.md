# 🎤 Speech Speed Analyzer

## 📌 Project Description

Speech Speed Analyzer is a simple Python project that analyzes an audio recording and estimates the speaking speed. It measures the audio duration and classifies the speech as **Slow, Normal, or Fast**.

The project also displays the audio waveform for better visualization.

## 🛠️ Technologies Used

* Python
* Google Colab
* Librosa
* NumPy
* Matplotlib
* SciPy

## ✨ Features

* Analyze speech audio
* Calculate audio duration
* Estimate speaking speed
* Classify speech as Slow, Normal, or Fast
* Display audio waveform
* Automatically create a sample audio file
* Beginner-friendly implementation

## ▶️ How to Run

1. Open **Google Colab**.
2. Create a new notebook.
3. Copy and paste the project code.
4. Run the code.
5. The program automatically creates a sample audio file.
6. The audio is analyzed automatically.
7. View the speech speed and waveform.

## 📊 Sample Output

```text
===== SPEECH ANALYSIS =====

File: sample_speech.wav
Sample Rate: 22050 Hz
Duration: 10.0 seconds
Average Volume: 0.2125
Speech Speed: Normal
```

The project also displays a waveform graph of the audio.
